# Prompt reutilizável — gerar sequência de Stories

Monte uma sequência de 3 a 5 Stories sobre **[tema]**, para **[persona]**, com objetivo **[objetivo]**. Inclua texto de cada tela, sticker sugerido, resposta esperada, CTA e orientação visual.

Use interação para ouvir médicos, não para coletar dados de pacientes. Se o tema for clínico, escreva como educação geral e peça validação humana. Não transforme resposta de enquete em conduta individual.
